# 豆豆工坊

单机拼豆库存与图纸辅助工具。所有库存、图纸和拼制进度保存在当前浏览器的 localStorage 中，不会上传到服务器。

## 使用

- 打开页面后，221 个色号 A1-A26、B1-B32、C1-C29、D1-D26、E1-E24、F1-F25、G1-G21、H1-H23、M1-M15 均以 1000 颗初始化。
- 在“图纸”页上传图纸截图，分别框选网格和底部色号统计，并填写实际行列数（不含坐标）。手机可放大图片后先点左上角，滚动后再点右下角。图例范围需包含色号及数量。
- 使用本地 PP-OCRv4 模型读取分割后的图例，按原图底色匹配网格，并对相近颜色、疑难格复核文字。图片不会上传。首次使用下载约 13 MB 压缩资源，每块最多 256 KB；下载失败后复用已缓存分块，并显示进度。资源逐块及整包校验后才启动识别，成功缓存后可离线识别。
- 底部统计保留原图缩略图，可逐项修正色号和数量。待校对格显示红色问号，可定位并查看原图局部；不会按统计数字强行填色。库存扣减优先采用保存后的底部统计，网格差异或问号不阻止扣减；没有底部统计时按网格计算，存在问号则需先校对。确认弹窗会列出实际扣减的每色用量，库存不足仍会阻止扣减。
- 对未识别格子，可在预览网格中选色修正；也可以展开手动导入，粘贴色号网格。
- 图纸支持单色高亮、缩放、逐格进度、左右/上下镜像副本、顺时针旋转副本和 PNG 导出。
- 防止框选偏移：先粗选网格、填行列数，再点击“固定网格对齐 / 精调选区”。网格固定，拖动图片或按 1 像素微调，可缩放图片或直接调整原图选区坐标。查看放大至 2×/4×后，切换“移动视野”检查四角和中间格线，再点“应用对齐”。取消不会改变原选区。适用于规则截图，不自动检测格线或校正透视。
- 开始拼豆后，选择当前色号并开启“单色高亮”，其他颜色淡出且不可误点；色号文字随格显示。支持左右/上下镜像和恢复原方向，镜像只改变视图，完成标记仍记录在原格子上，重新打开后保留方向。编辑页的镜像副本功能仍可用于生成独立图纸。
- 库存仅在“完成并扣库存”时扣减。可随时导出 JSON 备份。
- GitHub Pages 部署：将仓库默认分支命名为 `main` 并推送；在仓库 Settings → Pages 中启用 GitHub Actions。

## 本地预览

用任意静态文件服务器从仓库根目录提供文件即可。部署后支持离线打开；数据仅保存在该浏览器/设备，清理浏览器数据前请先导出备份。

也可使用 Node.js 20+ 执行 `npm start`。测试说明见 [tests/README.md](tests/README.md)，本次四图实测、局限及开源调研见 [识别报告](docs/recognition-report.md)，模型来源见 [第三方声明](THIRD_PARTY_NOTICES.md)。

## 首次下载困难时

展开图纸页“首次下载失败？导入离线识别包”，选择 `vendor/ocr/countbean-ocr.cbocr` 文件。可在网络正常的设备下载后传到目标设备；页面已加载时，即使断网也能导入并识别。导入只保存引擎缓存，不改库存或图纸。无需解压，不要在库存备份导入入口选择此文件。

部署包含同源压缩分块，无需把图纸发送给第三方。使用 `node tools/build-ocr-assets.cjs` 从原始 OCR 资源重新生成分块清单和离线包；应一起发布，旧资源缓存继续兼容。
