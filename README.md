# 豆豆工坊

单机拼豆库存与图纸辅助工具。所有库存、图纸和拼制进度保存在当前浏览器的 localStorage 中，不会上传到服务器。

## 使用

- 打开页面后，221 个色号 A1-A26、B1-B32、C1-C29、D1-D26、E1-E24、F1-F25、G1-G21、H1-H23、M1-M15 均以 1000 颗初始化。
- 在“图纸”页上传图纸截图，分别框选网格和底部色号统计，并填写行列数。程序只对少量底部色号做 OCR，再按底部色块采样匹配网格；图片不会上传。首次 OCR 需要联网加载 Tesseract.js 和英文识别数据。
- 对未识别格子，可在预览网格中选色修正；也可以展开手动导入，粘贴色号网格。
- 图纸支持单色高亮、缩放、逐格进度、左右/上下镜像副本、顺时针旋转副本和 PNG 导出。
- 库存仅在“完成并扣库存”时扣减。可随时导出 JSON 备份。
- GitHub Pages 部署：将仓库默认分支命名为 `main` 并推送；在仓库 Settings → Pages 中启用 GitHub Actions。

## 本地预览

用任意静态文件服务器从仓库根目录提供文件即可。部署后支持离线打开；数据仅保存在该浏览器/设备，清理浏览器数据前请先导出备份。
